# DwemerWorks Asset Management System

A web-based IT Asset Management solution developed to help organizations track, monitor, and manage their technology assets throughout their lifecycle.

## Features

- Asset registration and inventory management
- Asset status tracking (Active, Repairing, Returned, Lost, Inactive)
- Location and user assignment management
- Asset filtering and search capabilities
- Interactive dashboard with charts and analytics
- Asset value and inventory statistics
- Acquisition year tracking
- Category and asset type management

## Dashboard Metrics

The system provides real-time visual reports including:

- Assets by type
- Assets by location
- Asset status distribution
- Acquisition trends
- Total assets
- Assets under repair
- Available assets
- Total asset value

## Technologies Used

- Java
- JSP / Servlet
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Chart.js
- MySQL

## Purpose

This project was developed as part of a Software Engineering academic project, simulating a real-world IT asset management environment commonly used by organizations to control equipment, inventory, allocation, and maintenance processes.
